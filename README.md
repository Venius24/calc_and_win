# Рассчитай и победи

Консольная учебная игра на Python. За пять атак нужно набрать суммарный урон с отклонением не больше 10 очков от здоровья противника. Здоровье (80–120) показывается в начале раунда; результат каждой атаки случаен.

```powershell
python main.py
```

Каждый ход вводите `lite` (2–5 урона), `mid` (15–25) или `hard` (30–40). После пяти ходов введите `y`, чтобы сыграть снова, либо `n` для выхода. Ошибочный ввод запрашивается повторно и не тратит ход. Дополнительные пакеты не нужны.

Для проверки: `python -m unittest discover -v`. Игра не сохраняет результаты между запусками.

Репозиторий: https://github.com/Venius24/calc_and_win
